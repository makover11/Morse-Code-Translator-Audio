
# Morse Code Audio Translator

A free and easy-to-use Morse Code Audio Translator that converts text into Morse code, decodes Morse code into readable text, and translates Morse audio signals. This tool is useful for students, developers, radio operators, and Morse code enthusiasts.

🌐 Website: https://justmorsecodetranslator.com/morse-code-translator-audio/

## Features

- Text to Morse code conversion
- Morse code to text decoding
- Instant real-time translation
- Decode Morse code using microphone input
- Upload and decode Morse code audio files
- Generate and play Morse code sounds
- Download Morse code audio as WAV files
- Adjustable playback speed and tone pitch
- Farnsworth speed control
- Volume and noise threshold adjustment
- Automatic frequency detection
- Live audio waveform visualizer
- Copy text and Morse code
- Export translations as TXT files
- Built-in Morse code reference chart
- Beginner-friendly interface

## Try It Online

Use the live Morse Code Audio Translator through the website linked above.

## How It Works

1. Enter normal text or Morse code.
2. The translator instantly converts the input.
3. Use the microphone or upload an audio file to decode Morse signals.
4. Play generated Morse code audio.
5. Adjust playback speed, pitch, and volume.
6. Copy the result or download it as TXT or WAV.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Morse-Code-Translator-Audio.git
```

Open the project folder and run the HTML file in your browser.

Replace `YOUR-USERNAME` with your GitHub username.

## Usage Example

### Text to Morse

Input:
```text
HELLO
```

Output:
```text
.... . .-.. .-.. ---
```

### Morse to Text

Input:
```text
... --- ...
```

Output:
```text
SOS
```

## Audio Decoder

The audio decoder allows users to:

- Detect Morse signals using a microphone
- Upload audio recordings for decoding
- Convert recognized dots and dashes into text
- Monitor signals using a waveform visualizer

Note: Audio decoding accuracy depends on background noise, signal clarity, and Morse timing.
